# Условаие задачи:
**Свойство текста**: в тексте содержится подстрока, состоящая из 3-х и более идущих подряд одинаковых символов 

**Правило 1**: заменить все символы текста символом из наиболее длинной подстроки одинаковых символов (пример: “12aaa3bb45” → “aaaaaaaaaa”)

**Правило 2**: каждую цифру в тексте (от 1 до 9) заменить на символ, находящийся правее цифры на число позиций, равное цифре (если длины строки не хватает, то цифру следует заменить звёздочкой) (пример: “abc1t92vr” → “abctt*rvr”)

# Запуск программы:
Программу можно скомпилировать при помощи `sh`-файлов.
- `compile.sh` - Запуск компиляции всех файлов
- `run.sh` - Запуск программы, после компиляции
- `remove_o.sh` - Очистка всех файлов с расширением (Объектных) `.o`

## Пример запуска программы:
Для начала Вам нужно скомпилировать файлы. Выполните скрипт

```bash
./compile.sh
```
В результате Вы получите объектные файлы (с расширением `.o`) и исполняемый файл `program`

Для запуска программы выполните скрипт 

```bash
./run.sh
```

После этого запустится программа, скомпилированная из Файлов Асемблера и управляющего файла, написанного на C++
